帮助与反馈

遇到使用问题或有改进建议，可通过 GitHub 提交反馈。请说明应用版本、macOS 版本和复现步骤；公开反馈中请勿包含私人记录。

我的记录保存在哪里？

当前版本保存在本机，无需账号，不提供云同步。更新前建议在“设置 → 导出完整资料库备份”中导出一份备份，并另存到其他设备。

从旧版或备份导入

首次打开商店版时，选择“从旧版或备份导入”，再选择含 IdeaVault.store 或 IdeaVaultLocal.store 的文件夹。请先退出旧版应用，并完整保留备份文件夹，包括隐藏的照片附件目录。导入会保留原文件。

资料库无法打开怎么办？

请保留原始资料库和备份，记录错误提示，通过上方入口联系开发者。请勿为了排错先清空应用数据。
