更新日期：2026 年 10 月 23 日 · 适用于首个本地保存版本

资料保存在你的设备

日拾记当前版本无需注册或登录。日记、心情、计划、打卡、账目、物品资产、旅行安排及你添加的照片与附件保存在本机资料库。应用不把这些记录上传到开发者服务器，当前版本不提供 iCloud 同步。

照片与附件

只有你主动选择的照片和文件会被导入。图片缩放、缩略图和主体抠图在设备上处理；移除应用内副本不会删除原相册或原文件。应用不要求访问整个磁盘。

联网功能

地点搜索、地图与路线使用 Apple 地图服务，会向 Apple 发送查询地点或路线所需的信息。收藏链接的网页预览可能访问对应网站并读取标题和图片。打开外部搜索或网页时，相应服务可能接收网址、查询词及网络连接信息，并适用其隐私政策。日记正文和账本内容不会因这些功能自动上传。

通知与偏好

番茄钟通知由你选择开启，拒绝通知权限不影响其他功能。主题色和计时偏好保存在本机。应用未集成广告、跨应用追踪或第三方用户行为分析 SDK。

备份、保留与删除

应用打开已有资料库前会在本机创建备份。你也可以导出包含记录和附件的完整资料库备份。回收站、自动备份和已导出的副本可能仍保留已删除记录；删除一条记录不会自动删除所有历史副本。请妥善保管备份，资料库备份未整体加密；已设置密码的存钱账本保留其加密内容。

你的选择

你可以在应用内查看、修改、删除和导出资料，或在系统设置中撤销通知等权限。更换或丢失设备前，请自行保存设备之外的备份；本地备份无法代替异地备份。

联系与政策更新

隐私问题和使用反馈可通过应用中的“帮助与反馈”入口提交。若今后加入账号、云同步或新的数据处理方式，我们会更新政策并提供必要的选择。

联系开发者

可在 GitHub 支持页面提交隐私问题或使用反馈。该页面公开显示反馈，请勿附上私人日记、账目、密码或完整资料库。

此网页的托管

本网站由 GitHub Pages 托管。访问网站时，GitHub 可能处理 IP 地址等网络信息，适用 GitHub 隐私声明。网站不设置广告或分析脚本，也不接收应用资料库。
